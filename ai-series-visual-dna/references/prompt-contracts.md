# 公共产物契约

## 适用范围

本文件只保存 `STYLE-BASE` 的交付、版本和公开边界。内容规则由 `SKILL.md` 路由到对应契约。

## 通用规则

- 正式产物只使用 `STYLE-BASE` 标识。
- 正式提示词正文全部使用英文；解释和覆盖状态使用中文。
- 不把分析、评分、失败记录、导演标签、具体实体清单或提示词拼接说明写入正式提示词。
- 默认不公开候选、测试组、分数或修订记录。用户明确要求查看审核或测试提示词时，只返回已经放行且必要的内容。

## 文件交付

只创建当前产物：

```text
<项目根目录>/DNA/
└── STYLE-BASE-[实际发布版本].md
```

- 文件名必须与产物 ID 完全一致，包括 `draft-v0.x`。
- 不移动、覆盖或删除旧版；重生成使用新的版本化文件名。
- `STYLE-BASE` 文件只保留标题和一个 `text` 代码块。
- 正式交付以文件为准；聊天只返回链接和一句状态。

## 版本与继承

- 源材料完整且全部门禁通过时首次发布 `v1.0`；材料不完整时使用 `draft-v0.x`。
- 修改视觉本体、题材表达、超常规则的视觉边界、综合色、光源体系、成像介质或材质逻辑时递增主版本。
- 仅压缩措辞且可见结果不变时递增次版本。

## 阶段交接

- `STYLE-BASE-[实际发布版本]` 是角色建模、场景建模和视频风格转译的唯一全局风格来源。
- 交接必须同时返回精确产物 ID 与当前文件路径；禁止使用 `latest`、`current` 或未版本化路径。
- 发布后立即停止并等待用户明确确认；确认后把精确版本交给 `ai-series-art-director`，本 Skill 不创建、不调用也不代行任何下游产物。
- 用户确认只放行当前精确版本。重发新版本后必须重新确认，旧确认不得自动继承。

## 确定性校验

写入后运行：

```powershell
python scripts/validate_artifacts.py <STYLE-BASE.md>
```

脚本只检查文件结构、语言和画幅并报告词数，不校验真人本体、题材保真或视效融合；语义继承、视觉因果和审核放行仍按阶段契约执行。
