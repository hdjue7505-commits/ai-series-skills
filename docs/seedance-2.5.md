# Seedance 2.5：从分镜主稿到生成入口

[返回首页](../README.md) · [安装与上手](quick-start.md) · [制作指南](workflow.md)

oh-my-director 面向 Seedance 2.5 组织创作准备，把故事、风格圣经、参考资产和分镜交给同一条生产链。当前不包含 Seedance API 客户端或自动提交功能，也不宣称官方合作或未经验证的平台能力。

## 交接的不是一句提示词

| 材料 | 交接内容 | 核对重点 |
| --- | --- | --- |
| 剧本 | 本场正文及原文对白 | 来源路径、场次、版本与覆盖范围。 |
| 风格圣经 | 已确认的精确 `STYLE-BASE` | 美术与分镜继承同一版本。 |
| 参考资产 | `approved ASSET-INDEX`、本场实体文件及实际参考图 | 标签与文件一一对应，图片不是 pending，素材使用权明确。 |
| 分镜主稿 | 场戏计划与片段 `Seedance 2.5 Prompt` | 镜头顺序、动作因果、对白分配及片段衔接。 |
| 白膜预演 | 每片段独立视频与检查状态 | 用于检查调度；不能替代正式美术，也不默认可作为平台输入。 |

## 提交前，核实你实际使用的入口

不同产品入口与账户配置可能不同。记录入口名称、模型版本、核验日期与依据；未核实项标为待核实，不用猜测值填满表格。

- **片长与画幅：** 当前入口支持的时长、分辨率、画幅与帧率。
- **参考素材：** 支持的图片、视频或音频类型、数量、尺寸和大小限制，以及各参考槽位的用途。
- **提示词：** 长度限制、引用语法；把内部 `@参考标签` 映射到真实素材和入口槽位，不假定平台直接识别这些标签。
- **对白与声音：** 是否支持所需语言、发声或口型控制；不能把主稿中的对白绑定当作平台执行保证。
- **使用权限与费用：** 素材授权、账户权限、实际计费及提交范围，由执行生成的一方确认。

## 创作片段不等于单次生成任务

本仓库的分镜片段采用 `0 < duration <= 30s`、每片段 6–12 镜。这是内部叙事规则，**不是 Seedance 2.5 的能力声明**。

如果实际入口不能承接某个片段，只能在已有镜头边界派生提交包，保留源片段与镜头编号映射，不新增镜头、不重复或遗漏台词，不静默改写已批准主稿。无法无损拆分时，报告具体冲突并回到分镜修订。

白膜先回答“安排是否成立”，正式生成再验证“画面是否实现”。生成结果仍需检查身份、动作、声音、连续性与视听质量，然后进入声音制作、剪辑和成片验收。

## 新版与旧项目

新片段使用 `### Seedance 2.5 Prompt`。校验器和白膜工具同时支持旧标题 `### Seedance 2.0 Prompt`，一个片段只允许一个受支持的提示词区块。

无需为改标题批量重写旧项目。已有白膜绑定了源文件指纹，即使只改标题也会改变文件哈希；保留旧版，实质修订时按原版本流程处理。本次兼容不放宽资产、对白、镜头或白膜来源校验。
